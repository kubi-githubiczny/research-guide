# Interview Field Guide

Interview tool for the ELISAVA Design Research Challenge (Research Module).
Live at https://research.jankowski.digital

- `index.html` - the whole tool (setup, timeline interview, review, PDF export, team archive)
- `netlify/functions/api.mjs` - saves interviews to Netlify Blobs
- Team code: Netlify environment variable `TEAM_CODE` (not stored in this repo)
